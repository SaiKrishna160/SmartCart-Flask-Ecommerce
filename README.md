# SmartCart - Flask E-Commerce Application

## Features

- Admin Login & Dashboard
- Product Management
- User Registration & Login
- Shopping Cart
- Razorpay Payment Integration
- Invoice PDF Generation

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap

## Run Project

```bash
pip install -r requirements.txt
python app.py
```
